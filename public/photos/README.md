# Фото для карточек «Для любой встречи»

Положи сюда настоящие фото, и главная страница покажет их вместо иллюстраций.
Имена файлов (подойдут .jpg, .jpeg, .webp, .png), лучше пропорция 4:3, до 300 КБ:

- `birthday` — дни рождения
- `party` — вечеринки
- `outdoors` — выезды на природу
- `bookclub` — книжные клубы
- `running` — пробежки
- `boardgames` — настольные игры

Пример: `public/photos/birthday.jpg`. После добавления файлов пересобери сайт (`npm run build`).
Используй фото, на которые у тебя есть права (свои или с бесплатных стоков вроде Unsplash/Pexels с подходящей лицензией).
